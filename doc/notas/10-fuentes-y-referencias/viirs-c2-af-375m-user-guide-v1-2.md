# VIIRS C2 Active Fire 375 m – User Guide v1.2

## Contenido
Guía de usuario del producto VIIRS Collection 2 de focos activos a 375 m. Define el algoritmo de detección, los campos del dataset (incluida la potencia radiativa del fuego, FRP), la confianza de la detección y las características de resolución espacial/temporal. Es la fuente primaria para justificar los datos de focos activos que muestra Meteovisor.
