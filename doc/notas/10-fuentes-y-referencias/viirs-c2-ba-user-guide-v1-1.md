# VIIRS C2 Burned Area – User Guide v1.1

## Contenido
Guía de usuario del producto de área quemada (Burned Area) de VIIRS Collection 2. Describe la metodología de cartografiado de superficie quemada, los campos del producto y sus limitaciones. Útil para el apartado de área quemada y para comparar el enfoque NASA frente al de Copernicus/EFFIS.
