# Normalización de datos de múltiples fuentes

## Contenido
Es necesario recoger la información procedente de todas las fuentes relevantes del sistema y transformarla a un conjunto de datos comunes, homogéneos y explotables de forma sencilla, de modo que el tratamiento posterior sea independiente de la fuente original. Esta idea apunta a definir un modelo de datos compartido o una capa de normalización que reduzca el acoplamiento con cada proveedor y facilite consultas, análisis, visualización e integración de nuevas fuentes.

## Datos explícitos
- Hay que recoger la información de todas las fuentes.
- Esa información debe transformarse a datos comunes.
- El objetivo es poder explotar los datos fácilmente.
- La explotación debe ser independiente de la fuente.

## Datos inferidos
- La idea sugiere diseñar un modelo de datos unificado o una capa de normalización.
- Esta normalización afectará al pipeline de ingestión y al uso posterior de los datos en el TFG.
- La nota parece ser una idea propia del trabajo y no una referencia externa.

## Datos faltantes o ambiguos
- Qué fuentes concretas deben entrar en esa transformación.
- Qué campos comunes formarán parte del modelo de datos.
- En qué fase del sistema se hará la normalización.
- Si esta idea se orienta más a base de datos, backend de ingestión o interfaz de consulta.
